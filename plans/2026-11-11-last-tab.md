# The Last Tab, Notes by Hover, Saving from the Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hover opens the expanded notch on the tab last clicked; a remembered Notes tab opens the notes panel without the keyboard; a save from a panel not opened by the shortcut comes back to the line.

**Architecture:** `LimitsNotchModel.pickedTab` (memory only) is set by tab clicks in the notch and the panel. `NotchPresenter.reconcileOnce` opens on it, and for Notes calls `onHoverNotes` (composer → `AppDelegate` → `NotesPanelPresenter.openFromHover()`) instead of expanding. `PanelTabRules.Opening` records how the panel opened: `.hover` opens Notes "glancing" (no keyboard, `PanelPointerWatch.opened(on:holdsKeyboard: false)`, closes on the pointer and for alerts) until the panel becomes key; every opening but `.shortcut` sets `NotesPanelModel.returnsAfterSave`, so "Saved" confirmations do not close the panel.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Swift Testing.

**Spec:** `specs/2026-11-11-polish-batch-design.md` §4 (and §9, §10).

## Global Constraints

- The shortcut keeps today's behaviour: Notes with the keyboard; a save closes the panel.
- An alert still shows on Sessions and does not change the picked tab.
- ⌘↩ (hand-off) closes the panel however it opened; failures and the folder prompt are unchanged.
- English only; no commits until the user says "коммить".

## Review Focus

1. Hover on Notes while the demo plays or the panel is open → the notch opens on Sessions instead.
2. A glancing panel clicked → it holds the keyboard; the pointer leaving no longer closes it; alerts wait.
3. A glancing panel and an alert → the panel closes and the alert shows.
4. A save from the Notes tab → "Saved" then the empty line with the keyboard in it; the new note in the list.
5. The shortcut pressed while a glancing panel is open → the panel takes the keyboard (spec §4.2: the shortcut means Notes with the keyboard).
