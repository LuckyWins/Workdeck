# Demo Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-minute scripted Claude Code tour in the notch, started from Settings → General, that writes nothing and leaves the real controllers untouched.

**Architecture:** An app-level `DemoMode` engine (`Workdeck/Core/Demo/`) keeps a cycle clock and ticks registered `DemoParticipant`s once a second. `ClaudeCodeController` is the first participant: while the demo runs, `refresh()` builds the notch state from a pure `ClaudeCodeDemoScript` frame through the same presentation code as real data, and the script's events go through the presenter's existing `flash` and `showRecap` plus a new `expand(for:)`.

**Tech Stack:** Swift 6 (MainActor default isolation), SwiftUI, Observation, Swift Testing, DynamicNotchKit (unchanged).

**Spec:** `specs/2026-10-14-demo-mode-design.md`

## Global Constraints

- English only in UI strings, comments and docs; commits follow Conventional Commits, no `Co-Authored-By`, no mention of AI tools.
- Commit only when the user says so: the commit steps below are run at the end, after the user's check, as one or more commits; executors stage nothing on their own.
- Pure value types are `nonisolated`; no new third-party dependencies; do not edit `project.pbxproj` (synchronized folders pick up new files).
- Demo writes nothing: no files, no `UserDefaults`, no Keychain, no recap history, no power assertions (spec §1 Goals).
- Tests never touch the real Keychain, network, `~/.claude*`, sessions or snapshots.
- Test command: `xcodebuild -scheme Workdeck -destination 'platform=macOS' test -only-testing:WorkdeckTests/<Suite> 2>&1 | grep -E "error:|recorded an issue|Test run with|\*\* TEST"`; full suite without `-only-testing`.

## Review Focus

1. "Without a notch → Menu bar text" on a Mac without a camera housing: the demo must draw the virtual notch (the presenter's screen closure in `AppDelegate`), and the menu bar text must come back at stop. Not unit-testable; manual row D2.
2. The pointer resting on the notch while the demo's recap is up: the presenter repeats the recap minute while hovered; the demo's `hideRecap` at the cycle's start must still close it. Pinned by Task 3's test `showRecapNilEndsAHoveredRecap`.
3. A first threshold of 95 % or 50 %: the 5-hour window must reach exactly that threshold at 30 s and the alert carry it. Pinned in Task 1 (`theThresholdFollowsSettings`).
4. A real alert or a real recap arriving during the demo must not show during it nor burst out after stop. Pinned in Task 4 (`realAlertsAreDropped`, `aRealRecapWaitsForTheStop`).
5. The Statistics window left open across start and stop: it switches to demo weeks and back. Pinned in Task 4 (`statisticsFollowTheDemo`).

```swift
import Foundation

/// One account in a demo frame.
nonisolated struct ClaudeCodeDemoAccount: Equatable, Sendable {
    var name: String
    var plan: String
    var windows: [UsageWindow]
    var age: TimeInterval
}

/// What the notch shows at one moment of the demo.
nonisolated struct ClaudeCodeDemoFrame: Equatable, Sendable {
    var accounts: [ClaudeCodeDemoAccount]
    var sessions: [ClaudeSession]
}

nonisolated enum ClaudeCodeDemoEvent: Equatable, Sendable {
    /// Expands the notch for this many seconds.
    case expand(TimeInterval)
    case alert(LimitsAlert)
    case showRecap
    case hideRecap
}

/// The one-minute Claude Code tour (demo mode spec §2.2). Pure: the same moment gives the same frame, so every cycle
/// and every recording look alike. Times are relative to `now`, so ages read naturally.
nonisolated enum ClaudeCodeDemoScript {
    static let cycleLength: TimeInterval = 60
    static let expandedSeconds: TimeInterval = 6
    static let personal = "personal"
    static let orbitID = "demo-orbit-app"
    static let apiID = "demo-api-server"
    static let orbitWorked: TimeInterval = 14 * 60

    private static let orbitFinishesAt: TimeInterval = 42
    private static let fiveHourResetsIn: TimeInterval = 3 * 3600 + 10 * 60

    private struct Step {
        let action: String
        var lines: LineCounts?
    }

    private static let orbitSteps = [
        Step(action: "Read OrbitView.swift"),
        Step(action: "Grep \"orbitRadius\""),
        Step(action: "Edit OrbitView.swift", lines: LineCounts(added: 12, removed: 3)),
        Step(action: "Read PlanetModel.swift"),
        Step(action: "Edit PlanetModel.swift", lines: LineCounts(added: 8, removed: 2)),
        Step(action: "Bash swift test"),
        Step(action: "Read Package.swift"),
        Step(action: "Edit OrbitViewTests.swift", lines: LineCounts(added: 24, removed: 0)),
    ]

    private static let apiSteps = [
        Step(action: "Read routes.ts"),
        Step(action: "Edit routes.ts", lines: LineCounts(added: 18, removed: 4)),
        Step(action: "Bash npm test"),
        Step(action: "Read auth.ts"),
        Step(action: "Edit auth.ts", lines: LineCounts(added: 6, removed: 6)),
        Step(action: "Bash npm run lint"),
    ]

    private static let agentActions = ["Grep \"drawOrbit\"", "Read OrbitLayer.swift", "Glob **/*Orbit*.swift", "Read OrbitRenderer.swift"]

    /// Main's 5-hour window: climbs to the first threshold at 30 s, then 4 points more by the end.
    static func fiveHourPercent(at elapsed: TimeInterval, thresholds: [Int]) -> Double {
        let threshold = Double(thresholds.first ?? 80)
        let start = min(38, threshold - 12)
        if elapsed <= 30 {
            return start + (threshold - start) * elapsed / 30
        }
        return threshold + 4 * (elapsed - 30) / 30
    }

    static func frame(at elapsed: TimeInterval, now: Date, thresholds: [Int]) -> ClaudeCodeDemoFrame {
        let cycleStart = now.addingTimeInterval(-elapsed)
        let main = ClaudeCodeDemoAccount(
            name: ClaudeInstance.mainName,
            plan: "Max 5x",
            windows: [
                UsageWindow(kind: .fiveHour, usedPercent: fiveHourPercent(at: elapsed, thresholds: thresholds), resetsAt: cycleStart.addingTimeInterval(fiveHourResetsIn)),
                UsageWindow(kind: .sevenDay, usedPercent: 61, resetsAt: cycleStart.addingTimeInterval(2 * 86_400 + 5 * 3600)),
            ],
            age: 5
        )
        let other = ClaudeCodeDemoAccount(
            name: personal,
            plan: "Pro",
            windows: [
                UsageWindow(kind: .fiveHour, usedPercent: 12, resetsAt: cycleStart.addingTimeInterval(4 * 3600)),
                UsageWindow(kind: .sevenDay, usedPercent: 34, resetsAt: cycleStart.addingTimeInterval(4 * 86_400 + 2 * 3600)),
            ],
            // Last used the night before, until its session starts.
            age: elapsed < 10 ? 13 * 3600 : 5
        )
        var sessions = [orbitSession(at: elapsed, cycleStart: cycleStart, now: now)]
        if elapsed >= 10 {
            sessions.append(apiSession(at: elapsed, cycleStart: cycleStart, now: now))
        }
        return ClaudeCodeDemoFrame(accounts: [main, other], sessions: sessions)
    }

    /// The events after `previous` up to and including `elapsed`; `previous` is `nil` on the first tick and larger
    /// than `elapsed` after the cycle wrapped.
    static func events(after previous: TimeInterval?, upTo elapsed: TimeInterval, now: Date, thresholds: [Int]) -> [ClaudeCodeDemoEvent] {
        let cycleStart = now.addingTimeInterval(-elapsed)
        let threshold = thresholds.first ?? 80
        let window = UsageWindow(kind: .fiveHour, usedPercent: Double(threshold), resetsAt: cycleStart.addingTimeInterval(fiveHourResetsIn))
        let timeline: [(at: TimeInterval, event: ClaudeCodeDemoEvent)] = [
            (0, .hideRecap),
            (0, .expand(expandedSeconds)),
            (20, .alert(.sessionNeedsYou(project: "api-server"))),
            (30, .alert(.threshold(window, threshold: threshold))),
            (orbitFinishesAt, .alert(.sessionFinished(project: "orbit-app", worked: orbitWorked))),
            (50, .showRecap),
        ]
        guard let previous else {
            return timeline.filter { $0.at <= elapsed }.map(\.event)
        }
        if elapsed >= previous {
            return timeline.filter { $0.at > previous && $0.at <= elapsed }.map(\.event)
        }
        // The cycle wrapped: the end of the last one, then the start of this one.
        return (timeline.filter { $0.at > previous } + timeline.filter { $0.at <= elapsed }).map(\.event)
    }

    /// Twelve weeks of made-up days up to today, the same on every call (statistics spec, demo mode spec §2.3).
    static func days(now: Date, calendar: Calendar) -> [RecapDay] {
        let today = calendar.startOfDay(for: now)
        let thisWeek = RecapCalendar.weekStart(of: now, calendar: calendar)
        var result: [RecapDay] = []
        for week in 0..<RecapStore.keptWeeks {
            guard let start = calendar.date(byAdding: .weekOfYear, value: -week, to: thisWeek) else { continue }
            let factor = weekFactors[week % weekFactors.count]
            for weekday in 0..<7 {
                guard let date = calendar.date(byAdding: .day, value: weekday, to: start), date <= today else { continue }
                let minutes = dayMinutes[weekday] * factor
                guard minutes > 0 else { continue }
                result.append(day(date: date, minutes: minutes, weekday: weekday, calendar: calendar))
            }
        }
        return result.sorted { $0.date < $1.date }
    }

    /// Last week's recap from the demo's days.
    static func recap(now: Date, calendar: Calendar) -> WeeklyRecapSummary {
        let thisWeek = RecapCalendar.weekStart(of: now, calendar: calendar)
        let lastWeek = calendar.date(byAdding: .weekOfYear, value: -1, to: thisWeek) ?? thisWeek
        return WeeklyRecap.summary(days: days(now: now, calendar: calendar), weekStart: lastWeek, calendar: calendar)
    }

    // MARK: Sessions

    private static func orbitSession(at elapsed: TimeInterval, cycleStart: Date, now: Date) -> ClaudeSession {
        let isWorking = elapsed < orbitFinishesAt
        let finishedAt = cycleStart.addingTimeInterval(orbitFinishesAt)
        let workStart = finishedAt.addingTimeInterval(-orbitWorked)
        let last = Int(min(elapsed, orbitFinishesAt - 1) / 2)
        var session = ClaudeSession(
            id: orbitID,
            cwd: "/Users/demo/Projects/orbit-app",
            status: isWorking ? .working : .idle,
            since: isWorking ? workStart : finishedAt,
            lastEventAt: now
        )
        session.hostBundleID = "com.microsoft.VSCode"
        session.workStartedAt = isWorking ? workStart : nil
        session.lastStopAt = isWorking ? nil : finishedAt
        session.steps = steps(orbitSteps, upTo: last, every: 2, from: 0, cycleStart: cycleStart, idPrefix: "orbit")
        session.action = isWorking ? orbitSteps[last % orbitSteps.count].action : nil
        session.turn = turn(orbitSteps, upTo: last, startedAt: cycleStart)
        if elapsed >= 6, elapsed < 18 {
            session.agents = [exploreAgent(at: elapsed, cycleStart: cycleStart, now: now)]
        }
        return session
    }

    private static func apiSession(at elapsed: TimeInterval, cycleStart: Date, now: Date) -> ClaudeSession {
        let isWaiting = elapsed >= 20 && elapsed < 26
        // The steps pause while it waits for the permission.
        let working = elapsed < 20 ? elapsed - 10 : (isWaiting ? 10 : elapsed - 16)
        let last = Int(working / 3)
        let since: TimeInterval = elapsed < 20 ? 10 : (isWaiting ? 20 : 26)
        var session = ClaudeSession(
            id: apiID,
            cwd: "/Users/demo/Projects/api-server",
            status: isWaiting ? .waiting : .working,
            since: cycleStart.addingTimeInterval(since),
            lastEventAt: now
        )
        session.hostBundleID = "com.apple.Terminal"
        session.termProgram = "Apple_Terminal"
        session.instance = personal
        session.workStartedAt = cycleStart.addingTimeInterval(10)
        session.steps = steps(apiSteps, upTo: last, every: 3, from: 10, cycleStart: cycleStart, idPrefix: "api")
        session.action = isWaiting ? nil : apiSteps[last % apiSteps.count].action
        session.turn = turn(apiSteps, upTo: last, startedAt: cycleStart.addingTimeInterval(10))
        return session
    }

    private static func exploreAgent(at elapsed: TimeInterval, cycleStart: Date, now: Date) -> RunningAgent {
        let index = Int((elapsed - 6) / 2)
        var agent = RunningAgent(id: "demo-explore", type: "Explore", description: "Find where orbits are drawn", startedAt: cycleStart.addingTimeInterval(6))
        agent.action = agentActions[index % agentActions.count]
        agent.lastSeenAt = now
        agent.model = "haiku"
        agent.steps = index + 1
        return agent
    }

    /// The last `ClaudeSession.maxSteps` steps up to `last`, with IDs that stay the same from tick to tick.
    private static func steps(_ list: [Step], upTo last: Int, every interval: TimeInterval, from start: TimeInterval, cycleStart: Date, idPrefix: String) -> [SessionStep] {
        (max(0, last - ClaudeSession.maxSteps + 1)...last).map { index in
            let step = list[index % list.count]
            return SessionStep(
                toolUseID: "\(idPrefix)-\(index)",
                action: step.action,
                lines: step.lines,
                at: cycleStart.addingTimeInterval(start + interval * Double(index))
            )
        }
    }

    private static func turn(_ list: [Step], upTo last: Int, startedAt: Date) -> TurnEdits {
        var turn = TurnEdits(startedAt: startedAt)
        for index in 0...last {
            let step = list[index % list.count]
            guard let lines = step.lines else { continue }
            turn.edits += 1
            turn.added += lines.added
            turn.removed += lines.removed
            turn.files.insert(String(step.action.dropFirst("Edit ".count)))
        }
        return turn
    }

    // MARK: Days

    private static let projectShares: [(name: String, share: Double)] = [("orbit-app", 0.5), ("api-server", 0.3), ("design-system", 0.15), ("docs", 0.05)]
    /// Monday to Sunday.
    private static let dayMinutes: [Double] = [95, 140, 120, 160, 80, 25, 0]
    private static let weekFactors: [Double] = [1.0, 0.85, 1.15, 0.7]
    private static let projectFiles = [
        "orbit-app": ["OrbitView.swift", "PlanetModel.swift", "OrbitViewTests.swift", "Package.swift"],
        "api-server": ["routes.ts", "auth.ts", "db.ts"],
        "design-system": ["Button.tsx", "tokens.json"],
        "docs": ["README.md"],
    ]

    private static func day(date: Date, minutes: Double, weekday: Int, calendar: Calendar) -> RecapDay {
        let key = RecapCalendar.dayKey(date, calendar: calendar)
        var projects: [String: RecapProjectDay] = [:]
        for (name, share) in projectShares {
            let seconds = (minutes * share * 60).rounded()
            guard seconds >= 60 else { continue }
            let files = projectFiles[name] ?? []
            projects[name] = RecapProjectDay(
                seconds: seconds,
                sessionIDs: Set((0..<max(1, Int(seconds / 2400))).map { "demo-\(key)-\(name)-\($0)" }),
                files: Set(files.prefix(max(1, Int(seconds / 900)))),
                added: Int(seconds / 15),
                removed: Int(seconds / 45),
                commands: Int(seconds / 180),
                agents: Int(seconds / 1200)
            )
        }
        let orbit = projects["orbit-app"]?.seconds ?? 0
        // Thursdays hit the 5-hour limit once.
        let hits: Set<Date> = weekday == 3 ? Set([calendar.date(byAdding: .hour, value: 15, to: date)].compactMap { $0 }) : []
        return RecapDay(
            date: key,
            projects: projects,
            longest: RecapStretch(project: "orbit-app", seconds: (orbit * 0.6).rounded()),
            accounts: [
                ClaudeInstance.mainName: RecapAccountDay(hitWindows: hits, weeklyPeak: min(100, 18 + 14 * Double(weekday))),
                personal: RecapAccountDay(weeklyPeak: 8 + 4 * Double(weekday)),
            ]
        )
    }
}
```

```swift
import Foundation
import Observation

/// A tool that plays its own script while demo mode runs (demo mode spec §3).
protocol DemoParticipant: AnyObject {
    /// How long the tool's script runs before it repeats.
    var demoCycleLength: TimeInterval { get }
    func demoDidStart()
    /// `elapsed` is the time into the cycle; `previous` the last tick's (`nil` on the first, larger after a wrap).
    func demoTick(elapsed: TimeInterval, previous: TimeInterval?)
    func demoDidStop()
}

/// Plays every participant's script on one clock until stopped. Kept in memory only: after a relaunch the demo is
/// off (demo mode spec §2.1).
@Observable
final class DemoMode {
    private(set) var isActive = false

    @ObservationIgnored private var participants: [any DemoParticipant] = []
    @ObservationIgnored private let clock: () -> Date
    @ObservationIgnored private let tickInterval: Duration
    @ObservationIgnored private var startedAt: Date?
    @ObservationIgnored private var lastElapsed: TimeInterval?
    @ObservationIgnored private var tickTask: Task<Void, Never>?

    init(clock: @escaping () -> Date = { Date() }, tickInterval: Duration = .seconds(1)) {
        self.clock = clock
        self.tickInterval = tickInterval
    }

    func register(_ participant: any DemoParticipant) {
        participants.append(participant)
    }

    /// The longest script; shorter ones wait for it.
    var cycleLength: TimeInterval {
        participants.map(\.demoCycleLength).max() ?? 60
    }

    func start() {
        guard !isActive else { return }
        isActive = true
        startedAt = clock()
        lastElapsed = nil
        for participant in participants {
            participant.demoDidStart()
        }
        tick()
        tickTask = Task { [weak self, tickInterval] in
            while !Task.isCancelled {
                try? await Task.sleep(for: tickInterval)
                guard !Task.isCancelled, let self else { return }
                tick()
            }
        }
    }

    func stop() {
        guard isActive else { return }
        tickTask?.cancel()
        tickTask = nil
        isActive = false
        startedAt = nil
        lastElapsed = nil
        for participant in participants {
            participant.demoDidStop()
        }
    }

    /// Moves every participant to the current moment of the cycle; the timer calls it, tests call it directly.
    func tick() {
        guard isActive, let startedAt else { return }
        let elapsed = max(0, clock().timeIntervalSince(startedAt)).truncatingRemainder(dividingBy: cycleLength)
        for participant in participants {
            participant.demoTick(elapsed: elapsed, previous: lastElapsed)
        }
        lastElapsed = elapsed
    }
}
```
