Workdeck

Your Claude Code limits and sessions in the MacBook notch — and a Mac that stays awake with the lid closed.

Install

curl -fsSL https://luckywins.github.io/Workdeck/install.sh | bash

Paste in Terminal. Downloads the latest version into Applications and opens it — no "could not verify" prompt. macOS 26 or later. Read the script

What does Workdeck do?

💻 Closed-Lid Mode

Keeps the Mac awake with the lid closed; turns itself off on low battery or heat.

📊 Limits in the notch

Claude Code and Codex plan limits at a glance, with reset times and a forecast.

🤖 Live sessions

Every session working, waiting for you or idle, with its agents and last steps.

🔔 Alerts

A limit near its end, a session that needs you, a long session that finished.

📅 Weekly recap

Coding time by project, a Statistics window and a half-year activity grid.

🔒 Private

No account, no telemetry; prompts and answers are never stored.

After installing

  1. Click the Workdeck icon in the menu bar → gear → Settings, and Connect the Claude Code status line and session hooks (you see the exact change first).
  2. Try Settings → General → Try Demo for a one-minute tour.
  3. Updates install themselves: Workdeck tells you when a new version is out. Release notes
