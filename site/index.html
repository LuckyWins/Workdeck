Workdeck

Your Claude Code limits and sessions in the MacBook notch — and a Mac that stays awake with the lid closed.

Install

curl -fsSL https://luckywins.github.io/Workdeck/install.sh | bash

Paste in Terminal. Downloads the latest version into Applications and opens it — no "could not verify" prompt. macOS 26 or later. Read the script

How it works

  1. 1

    Turn on what you need

    Click the Workdeck icon in the menu bar. Each tool is one row: Closed-Lid Mode keeps the Mac awake with the lid closed, Claude Code and Codex show your limits and sessions. Connect them once in Settings.

  2. 2

    While you work

    The notch shows the limit closest to running out and how many sessions are working. It stays out of the way until something changes.

  3. 3

    Hover to see everything

    Rest the pointer on the notch: every account's 5-hour and weekly limits with reset times and a forecast, and every session with its agents, last steps and changed lines.

  4. 4

    When something needs you

    A limit at 80 % or 95 %, a session waiting for a permission, a long session that finished: the notch opens with the alert. Click it to jump to the right window.

  5. 5

    Out of limit? Carry on with another account

    Run a second Claude Code account side by side. In Chats, open any chat on the other account and continue where you stopped.

  6. 6

    Your week, on Monday

    On the first unlock of a week the notch shows last week: coding time by project, sessions, files, lines and limit hits.

  7. 7

    And everything before

    Statistics keeps half a year: any week in detail, an activity grid of days and your streak, for Claude Code and Codex.

After installing

  1. Click the Workdeck icon in the menu bar → gear → Settings, and Connect the Claude Code status line and session hooks (you see the exact change first).
  2. Try Settings → General → Try Demo for a one-minute tour.
  3. Updates install themselves: Workdeck tells you when a new version is out. Release notes
